# 🛒 Product Management System

A robust ASP.NET web application designed for managing product inventories, categories, and tracking product details efficiently.

## 🚀 Features

- 📌 **Product CRUD Operations:** Create, Read, Update, and Delete product listings.
- 📁 **Category Management:** Categorize products for easy searching and navigation.
- 📊 **Interactive Dashboard:** Clear overview of available products and system data.
- 🔍 **Search & Filter:** Easily find specific products using search functionality.
- 🛡️ **Clean Architecture:** Built following MVC (Model-View-Controller) design patterns.

## 🛠️ Tech Stack

- **Framework:** ASP.NET Core / MVC
- **Language:** C#
- **Frontend:** HTML5, CSS3, Bootstrap, Razor Views
- **Database:** Entity Framework Core / SQL Server
- **IDE:** Microsoft Visual Studio
